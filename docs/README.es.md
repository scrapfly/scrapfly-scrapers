# ScrapFly Scrapers 🕷️

[English](../README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · **Español** · [Русский](README.ru.md)

Este repositorio contiene scrapers de ejemplo, con fines educativos, para sitios web populares, usando la API de web scraping de [ScrapFly](https://scrapfly.io) y Python.  
La mayoría de los scrapers usan un stack sencillo:
- Python 3.10 o superior
- [El SDK de Python de Scrapfly](https://github.com/scrapfly/python-scrapfly) para enviar peticiones HTTP, evitar bloqueos y analizar el HTML con el selector [parsel](https://pypi.org/project/parsel/) incluido.
- [asyncio](https://pypi.org/project/asyncio/) para escribir código concurrente con la sintaxis async/await.
- [JMESPath](https://pypi.org/project/jmespath/) y [nested-lookup](https://pypi.org/project/nested-lookup/) para analizar JSON cuando hace falta.
- [loguru](https://pypi.org/project/loguru/) para los logs.

Para aprender más sobre web scraping y ver cómo extraer datos de estos sitios (y de muchos otros), consulta nuestros tutoriales completos en el [directorio scrapeguide](https://scrapfly.io/blog/tag/scrapeguide/).  

Para agentes de IA y herramientas de LLM, [llms.txt](../llms.txt) lista cada scraper con sus funciones y su salida de ejemplo, y explica cómo ejecutar un scraper y cómo escribir uno nuevo.

## Uso justo y aviso legal

Este repositorio contiene material de referencia _educativo_ para mostrar lo accesible que puede ser el web scraping; los programas incluidos no están pensados para usarse en scraping en producción.
Dicho esto, el equipo de Scrapfly actualiza y mejora todo este código de forma constante para ofrecer la mejor experiencia.

Scrapfly no ofrece asesoramiento legal y, como siempre, consulta a un abogado cuando crees programas que interactúen con sitios web de otras personas. Aun así, esta es una buena introducción general a lo que NO se debe hacer:
- No almacenes información de identificación personal (PII) de ciudadanos de la UE protegidos por el RGPD.
- No extraigas ni reutilices conjuntos de datos públicos completos, que en algunos países pueden estar protegidos por leyes de protección de bases de datos.
- No hagas scraping a un ritmo que pueda dañar el sitio web, y extrae solo datos disponibles públicamente.
